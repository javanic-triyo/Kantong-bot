Trading manual kamu (paper)

Modal pura-pura $1.000 terpisah. Keputusan 100% dari kamu.

BUY / SELL / TUTUP
Cara pakai
  1. Tombol membuka halaman GitHub. Login kalau diminta.
  2. Tap Run workflow, pilih pair dan BUY / SELL / TUTUP.
  3. Isi lot (mulai 0.01), cut loss dan target dalam pip. Contoh EUR/USD: cut loss 30, target 60. Untuk USD/IDR 1 pip = Rp1.
  4. Tap Run workflow hijau. Sekitar 30 detik kemudian ada notifikasi di ntfy.
  5. Cut loss dan target dicek bot setiap 15 menit. Satu posisi per pair; mau ganti, TUTUP dulu.

Riwayat trade

Cara kerja

  1. Trend 2 arah: tren naik → BUY saat harga koreksi lalu mantul. Tren turun → SELL saat harga naik sebentar lalu gagal. Target +1R, cut loss −0,5R.
  2. Breakout London: catat high/low sesi Asia (07:00–14:00 WIB). 14:00–19:00 WIB harga tembus ke atas → BUY, ke bawah → SELL. Cut loss di tengah range, target 2× risiko, ditutup paling lambat 22:00 WIB.
  3. Risiko tiap trade maks 1% modal. Lot dihitung dari jarak cut loss (minimum 0,01 lot). Spread sudah dihitung.
Simulasi saja, tidak ada uang asli. Bukan saran keuangan.
