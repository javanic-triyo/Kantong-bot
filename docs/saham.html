Cara ubah portofolio
  1. Tombol membuka halaman GitHub. Tap Run workflow.
  2. Isi kode saham, jumlah lot total sekarang, dan harga beli rata-rata (lihat di aplikasi sekuritas kamu).
  3. Lot 0 = hapus saham dari daftar. Saham baru wajib isi harga beli.

Nilai portofolio 3 bulan

Dihitung dengan jumlah lot sekarang × harga penutupan tiap hari.
